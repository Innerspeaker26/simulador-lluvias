# Simulador de lluvias 3D · costa norte del Perú

Visor 3D de lluvia e inundación urbana para Piura, Sullana, Tumbes, Talara, Paita, Chulucanas,
Chiclayo y Trujillo. Usa el relieve de
15 m de **GEM-15** (Google Research), imágenes Copernicus Sentinel-2 y edificaciones de Overture Maps.

Ábrelo con `?ciudad=` para elegir la ciudad:

- `index.html?ciudad=piura`
- `index.html?ciudad=sullana`
- `index.html?ciudad=tumbes`
- `index.html?ciudad=chiclayo`
- `index.html?ciudad=trujillo`, `talara`, `paita`, `chulucanas`

Para abrirlo con pines, usa `index.html?ciudad=piura&pin=-5.19450,-80.63280` (separa varios pines
con `;`).

Es una herramienta didáctica y exploratoria, no un mapa oficial de peligro.
